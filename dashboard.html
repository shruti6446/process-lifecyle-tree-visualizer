Process life-cycle model

Five conceptual OS states
01 · NEWProcess is created, e.g. by fork().
02 · READYEligible to run; awaiting CPU scheduling.
03 · RUNNINGInstructions execute on the CPU.
04 · WAITINGBlocked, e.g. during sleep or I/O.
05 · TERMINATEDExecution ends; parent may reap the child.
The five-state diagram is a teaching model. This C program logs START, SLEEP, WAKE and EXIT events; it does not directly measure the Linux scheduler's Ready or Running states.

Linux system-call reference

Key concepts demonstrated by the C program
fork()

Duplicates the calling process to create a child with a new PID.

getpid() / getppid()

Return the current process ID and its parent process ID.

sleep()

Suspends the calling thread for an interval; the trace logs this explicitly.

wait() / waitpid()

Collect a child's termination status and reap the child.

exit() / _exit()

Terminate a process; the simulator logs EXIT before termination.

PID / PPID

Identifiers used to construct the process tree and associate events.
